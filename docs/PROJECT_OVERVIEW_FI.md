# DigiVeli Security Lab — projektiesittely

**Secure AI. Secure Software. Safer World.**

DigiVeli Security Lab (DV-SecLab) on Suomessa käynnistetty itsenäinen, puolustavaan kyberturvallisuuteen keskittyvä tutkimus- ja kehitysprojekti.

## Tavoitteet

- Kehittää AI-agenttien luottamusrajojen ja työkalujen turvallisuutta.
- Vahvistaa verkkosovellusten, automaation ja CI/CD-putkien tietoturvaa.
- Tuottaa toistettavia, luvallisia turvallisuustestejä ja arvioituja korjauksia.
- Jakaa käytännönläheistä osaamista vastuullisesti kansainväliselle yhteisölle.

## Ensimmäinen tutkimusalue

**AI Harness Security Boundary Validation**: dokumentoidaan arkkitehtuuri ja todennetaan eristetyissä testiympäristöissä agenttien työkaluoikeudet, työtilarajat, prosessien hallinta, salaisuuksien käsittely ja auditoinnin eheys.

Testaaminen edellyttää aina omaa kohdetta tai yksiselitteistä lupaa. Kolmansien osapuolten järjestelmiä ei testata automaattisesti eikä keskeneräisiä löydöksiä julkaista ennen vastuullista käsittelyä.

Hanke ei väitä kuuluvansa OpenAI Daybreak -ohjelmaan eikä edustavansa muita organisaatioita.
